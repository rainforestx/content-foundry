## Voice target (pointer, not a restatement)

The base voice target and its form references live in form-references.md:
independent, audiologist-grade, consumer-readable. This file does not restate
it; it records how the operator's rulings refine it.

## How a ruling gets recorded

A ruling is the operator's reaction to a rendered article, made specific:
which passage, flexed toward which reader, in which direction. Verbatim where
possible. Each ruling carries a date, the article it arose from, and what was
done about it. Rulings are append-only; a later ruling can overrule an
earlier one but the earlier one stays visible.
